# Spec Delta

## Purpose

桌面端应用改用自绘窗口边框（隐藏系统装饰），呈现与整体视觉一致的玻璃标题栏：包含品牌区、拖拽移动、双击最大化、最小化/最大化/关闭控制；浏览器端降级为同款视觉的非交互头部，不出现无效控制按钮。

## ADDED Requirements

### Requirement: 自绘标题栏
桌面应用窗口 MUST 隐藏系统装饰（`decorations: false`），改由应用内标题栏承担窗口框架职责：品牌区 + 当前上下文标题 + 窗口控制区；标题栏视觉 SHALL 与整体玻璃风格一致。

#### Scenario: 桌面端窗口框架
- **WHEN** 桌面应用启动
- **THEN** 窗口无系统装饰，顶部为应用自绘标题栏，品牌与控件布局正确

#### Scenario: 浏览器端降级
- **WHEN** 应用运行于浏览器
- **THEN** 标题栏仅呈现品牌与上下文等非交互内容，不渲染最小化/最大化/关闭按钮

### Requirement: 窗口拖拽与双击最大化
标题栏空白区域 MUST 可拖动窗口（属性拖拽区 + 指针事件兜底），双击拖拽区 SHALL 在最大化与还原间切换。

#### Scenario: 拖动窗口
- **WHEN** 用户在标题栏空白处按住拖动
- **THEN** 窗口随指针移动（桌面端）

#### Scenario: 双击最大化
- **WHEN** 用户双击标题栏空白处
- **THEN** 窗口在最大化与还原状态间切换

### Requirement: 窗口控制按钮
桌面端标题栏 SHALL 提供最小化、最大化/还原、关闭三个控制按钮，行为与系统按钮一致；悬停时关闭按钮 SHALL 呈现危险色提示。

#### Scenario: 控制按钮行为
- **WHEN** 用户点击最小化/最大化/关闭
- **THEN** 窗口分别最小化、最大化或还原、关闭

### Requirement: 布局高度适配
引入标题栏后，应用内容区 MUST 恰好占满剩余视口高度，不出现双滚动条或内容被挤压；沉浸模式下标题栏 SHALL 保留（用于拖动窗口）。

#### Scenario: 无布局跳动
- **WHEN** 应用启动或窗口缩放
- **THEN** 内容区高度正确填满标题栏以下空间，无溢出滚动
