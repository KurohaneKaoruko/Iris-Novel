# Spec Delta

## Purpose

定义 Iris-Novel 的液态玻璃视觉语言：深色玻璃主题为默认外观，统一的令牌层（色板、圆角、投影、动效、玻璃配方）驱动全部组件，应用壳层（活动栏、侧栏、编辑区、状态条、弹窗）呈现一致的现代质感，且全部动效尊重减弱动效偏好。

## ADDED Requirements

### Requirement: 设计令牌层
系统 SHALL 以 CSS 自定义属性定义完整的视觉令牌：色板（含三级表面、发丝边框、语义状态色）、圆角阶梯、多层投影、缓动与时长、玻璃配方；深色与浅色两套主题 MUST 提供同构的令牌集合，组件仅依赖令牌不得硬编码颜色。

#### Scenario: 深色主题为默认
- **WHEN** 用户未显式选择主题
- **THEN** 界面呈现深蓝灰玻璃外观，全部表面/边框/文字取自深色令牌

#### Scenario: 浅色主题同构可用
- **WHEN** 用户切换到浅色主题
- **THEN** 全部组件呈现对应的浅色玻璃外观，无未适配的深色残留、无对比度不足的文本

#### Scenario: 令牌驱动组件
- **WHEN** 任一组件需要颜色/圆角/阴影
- **THEN** 其取值来自令牌变量，主题切换时无需组件级改动即可跟随

### Requirement: 玻璃质感基元
系统 SHALL 提供可复用的玻璃质感基元（面板与悬浮条两类），统一包含背景模糊、半透明表面、发丝边框与顶部高光；模糊效果 MUST 限制在壳层与弹层，正文内容区不得使用实时模糊以避免性能劣化。

#### Scenario: 玻璃面板渲染
- **WHEN** 侧栏、弹窗或悬浮条渲染
- **THEN** 呈现背景模糊 + 半透明底 + 发丝边框的统一玻璃质感，且在 WebKit 与 Chromium 内核下视觉一致

### Requirement: 应用壳层玻璃化
活动栏、侧栏、右栏、标签栏、弹窗 SHALL 呈现与令牌一致的玻璃质感与圆角；编辑区 SHALL 提供居中的书写栏（内容列限宽），底部状态区 SHALL 以悬浮玻璃胶囊呈现（含保存状态、字数与主题/语言入口），且不遮挡正文（内容区预留底部间距）。

#### Scenario: 工作台一致质感
- **WHEN** 用户打开作品进入工作台
- **THEN** 活动栏/侧栏/标签栏/右侧面板呈现玻璃质感，编辑区为居中书写栏，底部为悬浮状态胶囊

#### Scenario: 悬浮状态条不遮挡内容
- **WHEN** 正文滚动到底部
- **THEN** 最后一行文字不被悬浮状态胶囊遮挡

### Requirement: 弹层统一玻璃壳
所有模态弹窗（导出、设置、模型配置等）SHALL 使用统一的玻璃外壳：遮罩层半透明加深 + 背景模糊，面板玻璃质感 + 大圆角 + 悬浮投影；打开与关闭呈现缩放渐显过渡。

#### Scenario: 弹窗开合动效
- **WHEN** 用户打开或关闭任一模态弹窗
- **THEN** 遮罩与面板以缩放渐显方式过渡，关闭后不残留焦点或滚动锁

### Requirement: 减弱动效守护
系统 MUST 尊重 `prefers-reduced-motion` 与既有 `data-motion="reduced"` 设置：在减弱动效时，转场/悬浮/淡入等高开销动效 SHALL 退化为瞬时或最小位移切换。

#### Scenario: 减弱动效下退化
- **WHEN** 用户启用系统减弱动效或应用内对应设置
- **THEN** 页面转场与面板动效不再播放位移/缩放动画，仅瞬时切换
