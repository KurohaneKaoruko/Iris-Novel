# Spec Delta

## Purpose

让浏览器端获得与桌面端一致的功能：本地服务端以 HTTP/WebSocket 暴露与 Tauri 命令等价的能力，前端经统一传输适配层透明切换，桌面端行为保持不变。

## ADDED Requirements

### Requirement: 本地服务端命令等价 API
系统 SHALL 提供本地服务端，把现有 Tauri 命令的能力（工作区管理、文件 I/O、设置、聊天历史、书架状态等）以 HTTP API 等价暴露；同一逻辑同时服务 Tauri IPC 与 Web 两条通道，行为一致。

#### Scenario: 浏览器调用等价命令
- **WHEN** 浏览器端通过 HTTP API 调用与某 Tauri 命令等价的接口
- **THEN** 返回与桌面端调用该命令一致的数据结构与结果

#### Scenario: 桌面端行为不回归
- **WHEN** 服务端逻辑被提取共享后，桌面端执行任一既有操作
- **THEN** 其行为与提取前保持一致

### Requirement: AI 流式经 WebSocket 推送
AI 流式事件（开始、token、代理步骤、变更集、完成、错误）SHALL 通过 WebSocket 推送给浏览器端，事件语义与桌面端 Tauri 事件一致；浏览器端可取消进行中的流式任务。

#### Scenario: 浏览器接收流式 token
- **WHEN** 浏览器端发起 AI 流式生成
- **THEN** 客户端按序收到与桌面端相同语义的流式事件直至完成

#### Scenario: 浏览器取消流式
- **WHEN** 浏览器端在流式生成过程中请求取消
- **THEN** 服务端终止该任务并推送终止事件，与桌面端取消行为一致

### Requirement: 前端传输适配层
前端 SHALL 通过统一传输适配层访问全部后端能力：在 Tauri 环境自动走 IPC，在浏览器环境自动走 HTTP/WS；业务代码与组件不感知传输差异。

#### Scenario: Tauri 环境选择 IPC
- **WHEN** 应用运行于桌面端（检测到 Tauri 运行时）
- **THEN** 所有后端调用经 IPC 完成，不发起网络请求

#### Scenario: 浏览器环境选择 HTTP/WS
- **WHEN** 应用运行于标准浏览器
- **THEN** 所有后端调用经 HTTP/WS 完成，功能与桌面端一致

### Requirement: 服务端绑定与访问安全
本地服务端 MUST 默认仅绑定本机回环地址；跨来源访问 SHALL 受来源校验约束，未经用户明确配置不得暴露到外部网络。

#### Scenario: 默认仅本机可访问
- **WHEN** 用户以默认配置启动本地服务端
- **THEN** 服务仅监听回环地址，外部网络无法访问

### Requirement: 浏览器环境能力降级
浏览器环境不适用的桌面能力（系统原生对话框、操作系统密钥环等）SHALL 有明确的降级或替代实现（如浏览器文件下载、浏览器本地存储），不得导致功能崩溃或静默失效。

#### Scenario: 原生对话框降级
- **WHEN** 浏览器端触发导出等依赖系统对话框的操作
- **THEN** 系统改用浏览器下载或页内流程完成，用户获得等效结果

#### Scenario: 密钥存储替代
- **WHEN** 用户在浏览器端配置 API 密钥
- **THEN** 密钥保存于浏览器本地存储并在调用时可用，界面明确标示其与桌面端密钥环的差别
